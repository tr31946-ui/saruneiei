🌸 My E-Portfolio Website

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (Electronic Portfolio) สำหรับนำเสนอประวัติส่วนตัว ประวัติการศึกษา ผลงานทางวิชาการ กิจกรรม และเกียรติบัตรในรูปแบบเว็บไซต์ที่สวยงามและทันสมัย

พัฒนาด้วย HTML, CSS และ JavaScript โดยเน้นการออกแบบที่เรียบง่าย ใช้งานง่าย และรองรับทุกขนาดหน้าจอ

👩‍💻 Developer

ชื่อผู้พัฒนา: ศรัณย์พร พึงคล้าย

ชื่อโปรเจกต์: My E-Portfolio Website

✨ Features
🏠 Home – หน้าแรกและแนะนำตัว
👤 About Me – ประวัติส่วนตัวและประวัติการศึกษา
🏆 Portfolio – แสดงผลงานและความสำเร็จ
📚 Activities – กิจกรรม การอบรม และเกียรติบัตร
📩 Contact – ช่องทางการติดต่อ
📱 Responsive Design รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์
🎨 ดีไซน์โทนสี Pastel Blue และ Pastel Pink
✨ มีเอฟเฟกต์ Hover และ Smooth Scrolling
🛠️ Technologies Used
Technology	Description
HTML5	สร้างโครงสร้างเว็บไซต์
CSS3	ตกแต่งและออกแบบเว็บไซต์
JavaScript	เพิ่มการทำงานแบบ Interactive
Google Fonts	ใช้ฟอนต์ Prompt

🚀 Installation & Usage

1. Clone Repository

bash
git clone https://github.com/username/my-portfolio.git


2. เข้าไปยังโฟลเดอร์โปรเจกต์

bash
cd my-portfolio


3. เปิดเว็บไซต์

เปิดไฟล์ index.html ด้วย Google Chrome หรือเว็บเบราว์เซอร์อื่น ๆ

⚙️ Customization

ผู้ใช้งานสามารถแก้ไขเว็บไซต์ได้ตามต้องการ เช่น

แก้ไขชื่อและข้อมูลส่วนตัว
เปลี่ยนรูปโปรไฟล์เป็น profile.jpg
เพิ่มประวัติการศึกษา
เพิ่มผลงานและเกียรติบัตร
แก้ไขช่องทางการติดต่อ
ปรับเปลี่ยนสีและรูปแบบเว็บไซต์
🌐 Deployment with GitHub Pages

สามารถเผยแพร่เว็บไซต์ผ่าน GitHub Pages ได้ฟรี

สร้าง Repository บน GitHub
อัปโหลดไฟล์โปรเจกต์ทั้งหมด
เข้าไปที่เมนู Settings
เลือก Pages
เลือก Branch เป็น main
เลือก Folder เป็น / (root)
กด Save

เมื่อเผยแพร่สำเร็จ เว็บไซต์จะสามารถเข้าชมได้ผ่าน URL

text
https://username.github.io/my-portfolio/

🎨 Design Concept

เว็บไซต์ออกแบบในสไตล์ Minimal Pastel Portfolio

💙 Pastel Blue – สื่อถึงความรู้และความน่าเชื่อถือ
💗 Pastel Pink – สื่อถึงความอ่อนโยนและความคิดสร้างสรรค์
🤍 White – เพิ่มความสะอาดตาและความเรียบง่าย
