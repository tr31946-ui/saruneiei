🌸 My E-Portfolio Website

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (Electronic Portfolio) สำหรับครูและบุคลากรทางการศึกษา พัฒนาด้วย HTML, CSS และ JavaScript เพื่อรวบรวมประวัติส่วนตัว ผลงานทางวิชาการ กิจกรรม และเกียรติบัตรไว้ในเว็บไซต์เดียว

✨ Features
🏠 Home – หน้าแรกพร้อมข้อความแนะนำตัว
👤 About Me – ประวัติส่วนตัวและประวัติการศึกษา
🏆 Portfolio – รวบรวมผลงานและความสำเร็จ
📚 Activities – กิจกรรม การอบรม และเกียรติบัตร
📩 Contact – ช่องทางการติดต่อ
📱 Responsive Design รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์
🎨 ออกแบบด้วยโทนสี Pastel Blue และ Pastel Pink
✨ เอฟเฟกต์ Hover และ Smooth Scrolling
🛠️ Technologies Used
Technology	Description
HTML5	โครงสร้างเว็บไซต์
CSS3	ออกแบบและตกแต่งเว็บไซต์
JavaScript	เพิ่มการทำงานแบบ Interactive
Google Fonts	ใช้ฟอนต์ Prompt
📂 Project Structure
text
my-portfolio/

🚀 Getting Started
1. Clone Repository
bash
git clone https://github.com/username/my-portfolio.git

2. เข้าไปยังโฟลเดอร์โปรเจกต์
bash
cd my-portfolio

3. เปิดเว็บไซต์

เปิดไฟล์ index.html ด้วยเว็บเบราว์เซอร์ เช่น Google Chrome

⚙️ Customization

สามารถแก้ไขข้อมูลในไฟล์ index.html ได้ตามต้องการ

เปลี่ยนชื่อและข้อมูลส่วนตัว
เปลี่ยนรูปโปรไฟล์เป็นไฟล์ profile.jpg
เพิ่มประวัติการศึกษาและความสามารถ
เพิ่มผลงานและเกียรติบัตร
แก้ไขอีเมลและช่องทางการติดต่อ
ปรับแต่งสีและรูปแบบเว็บไซต์ในส่วน CSS
🌐 Deployment with GitHub Pages

สามารถเผยแพร่เว็บไซต์ออนไลน์ได้ฟรีผ่าน GitHub Pages

สร้าง Repository บน GitHub
อัปโหลดไฟล์ทั้งหมดเข้าสู่ Repository
เข้าเมนู Settings
เลือก Pages
เลือก Branch เป็น main
เลือก Folder เป็น / (root)
กด Save

เมื่อ GitHub Pages เผยแพร่เว็บไซต์สำเร็จ จะได้รับ URL สำหรับเข้าชมเว็บไซต์

text
https://username.github.io/my-portfolio/

🎨 Design Concept

เว็บไซต์ออกแบบภายใต้แนวคิด Minimal Pastel Portfolio เน้นความเรียบง่าย สวยงาม และเป็นทางการ เหมาะสำหรับใช้เป็นแฟ้มสะสมผลงานออนไลน์

Pastel Blue – สื่อถึงความน่าเชื่อถือและความรู้
Pastel Pink – สื่อถึงความอ่อนโยนและความคิดสร้างสรรค์
White – ช่วยให้เว็บไซต์ดูสะอาดและอ่านง่าย
